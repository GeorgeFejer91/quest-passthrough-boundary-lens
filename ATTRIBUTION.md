# Attribution

This repository is derived from Rusty-XR and keeps the original MIT license
terms intact.

The upstream Rusty-XR codebase provided the Rust-native XR workspace, shared
runtime contracts, native Quest example structure, and OpenXR video-stack
foundation used by this project.

Quest Passthrough Boundary Lens extends that base with project-specific native
Meta Quest passthrough experiments, including Camera2/OES boundary rendering,
passthrough-underlay profiles, seam blending, homography and mesh-warp
calibration paths, and visual verification tooling.
